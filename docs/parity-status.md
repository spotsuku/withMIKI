# 現行HTML ⇄ 実装 パリティ状況

お父様が Claude チャットで作成した `legacy/` の HTML 3種と、本リポジトリの実装（先生用カルテ Web ＝ リポジトリ直下 / 患者用 PWA ＝ `patient/`）の対応状況。

凡例: ✅ 実装済 / 🟡 一部 / ⬜ 未

---

## アーキテクチャ対応（重要）

現行 HTML は「アプリ3種」だが、本実装は **役割で2アプリ**に再編している。

| 現行HTML | 役割 | 本実装の置き場所 |
|---|---|---|
| `personal-karte`（総合カルテ）| 先生用 | **リポジトリ直下のカルテWeb**（全対象を1つのカルテUIで管理）|
| `gyneco-daily-record`（婦人科）| 患者用 | **`patient/` PWA**（患者の主プログラム=婦人科のとき表示）|
| `athlete-record`（アスリート）| 患者用 | **`patient/` PWA**（患者の主プログラム=アスリートのとき表示）|

> **「カルテが1種類に見える」理由**：先生用カルテは設計どおり“共通1枚”（[02](02-database-design.md) の「共通基盤＋対象別モジュール」）。
> 婦人科/アスリートの違いは **患者ごとの「カルテ種別（ケアプログラム）」** で表現し、**患者アプリの入力画面が種別で切り替わる**。
> 患者登録時に種別（婦人科/アスリート/総合）を選べるようにした（本コミット）。先生画面では患者名の横に種別バッジを表示。
